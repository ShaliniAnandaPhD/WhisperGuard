# 📁 docs

Put your project's pictures and files here.

| File | Required? | What it is |
| --- | --- | --- |
| `maritime-dashboard.png` | ✅ Yes | A screenshot of your Maritime agent while it shows **Active**. Upload yours with this exact name to replace the placeholder. |
| `pitch-deck.pdf` | Optional | Your deck (up to 5 slides), if you'd rather not share it as a link. |
| Other screenshots | Optional | Anything that helps judges see your app. |

**How to upload:** click **Add file → Upload files** (top right of this folder), drag your files in, then click **Commit changes**.
